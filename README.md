# Mahendra LB Portfolio — Theme Edition

Open `index.html` directly in a browser or deploy the folder to Vercel/GitHub Pages.

## Theme selector
Use the **🎨 Theme** button in the navigation to switch between:
- Midnight Blue
- Ocean
- Royal Purple
- Emerald
- Sunset
- Clean Light

The selected theme is saved in the browser with localStorage.

## Deploy
For Vercel, upload/deploy this folder. `index.html` is at the project root and all CSS/JavaScript is embedded in the same file, so there are no stylesheet path issues.
